# 定稿视觉规则

## 画风与外观

以 `assets/reference.png` 为最终视觉依据：轻微三维感的干净扁平 Q 版插画，大头、小身体，圆润简洁的脸，大白色眼形配黑色椭圆瞳孔，极简鼻嘴。头发用整洁大块形状，不画密集毛发丝。柔和克制的明暗，平整色块、清楚边缘；不是照片、毛绒玩偶、油画或写实 3D 渲染。

照片决定身份特征，不把某个已有角色的脸套给新人。眉毛与发色协调；刘海分缝、眼镜轮廓、耳饰按照片或明确要求保留，不随机加呆毛或丢眼镜。

肤色服从照片和用户描述。暖小麦肤色用自然暖棕/金桃调，不能灰绿、过饱和橙红或脸手异色。默认均匀着色，不额外添加雀斑、腮红亮斑、噪点或白色脸部高光。用户本来有或要求保留的皮肤特征不擅自清除。眼白和皮肤分界清楚，避免眼白延伸成脸颊白点。

## 场景与物件

- `office`：白色桌面、深色办公转椅、电脑；显示器或笔记本服从用户说明。
- `home`：浅木桌、木椅或普通软包家用椅、银灰笔记本，作为默认。
- `floor`：仅在要求时使用坐垫、盘腿、矮桌，不加办公室转椅。

人、手、脚、家具、物件保持完整且比例协调；电脑不能挡住整张脸。道具只按请求添加。咖啡杯不能变成保温杯或大过头。

## SlashVibe 固定产品规格

每张图必须有且仅有一台，完整放在桌面上，不遮挡。外形看 `assets/product-stand.png`，定稿比例看 `assets/product-scale-reference.png`（只借产品比例，不借人物、服装或耳机）。旧团队参考里产品大小不能覆盖新定稿标准。

- 整体外接框宽 / 桌面投影外接框宽 = 约 10%，合格容差 9–11%；约为笔记本宽的 1/4。分辨率变化也保持此比例。
- 银灰色斜立圆角板、单条黑色斜线，与斜板明确连接的底座只朝画面左侧伸出。不可镜像、反向、双向伸出。
- 产品整体等比缩放，保持原始板与底座的内部比例和结构；自然透视应统一，不可把透视当作任意拉伸、压扁、弯曲或重设计的理由。
- 人物、桌面布局、宠物和职业变化时仍须保留产品。修改其它区域时锁定产品的尺寸、朝向与形状。

工具不保证逐像素一致。生成后要实际看图，变形、错误底座或过大均需修正，不能只凭 prompt 宣称通过。要求直接复制时使用现有资产复制/合成，不用再生成冒充复制。

桌面必须是透视一致的矩形平面，桌腿与对应角连接。纸张、书和设备完整落在桌面内，保留边距。书/草图默认朝向人物，屏幕不能画在笔记本盖背面。

## 宠物

无宠物请求则不画。照片决定毛色、花纹、虹膜，不默认复制其他成员的猫。绿色眼睛是绿色虹膜包围深色瞳孔，不是实心发光绿圆。暖灰虎斑不能变棕色；前爪、脸、耳和尾巴结构清楚，不融进设备。看向产品或举爪等动作只按请求添加。

## 实际看图的检查标准

1. 人数正确，照片中的关键特征可辨；没有复制整张团队合照。
2. 眼镜、眉毛、发型和配饰正确；脸轮廓无凹陷、撕裂或不规则突起。
3. 脸耳颈手肤色一致，无意外白点、杂色或纹理噪点，边缘不模糊。
4. 手臂、简化手掌、椅腿和鞋结构合理，无物件融合、截脚或截宠物。
5. 宠物毛色、虹膜、姿势、前爪符合请求，与人物清楚分开。
6. 每图恰好一台产品且完整落在桌面；宽度占桌面投影宽度 9–11%；斜板/底座比例无变形、相互连接，底座只向画面左侧伸出，无镜像。
7. 道具类别和数量符合请求，没有附带其他人的个性物件。
8. 透明底为真实 alpha，不是棋盘格；白底无纹理，无名字岗位水印。

发现局部问题先判断是否需要修改，不为了不存在的噪点反复处理整图；未经检验不承诺“零噪点”或“保证完全一样”。

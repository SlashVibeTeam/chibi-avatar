# SlashVibe Team Avatar

把用户照片转成与定稿一致的独立 Q 版人物。默认 **一人一图**，不是把用户塞进整张团队合照。

## 参考与输入

- 先用图像查看工具打开 [定稿参考图](assets/reference.png)，再阅读 [风格与检查标准](references/style-guide.md)。每次都查看 [产品底座参考](assets/product-stand.png) 和 [产品定稿比例参考](assets/product-scale-reference.png)；后者仅用于产品大小和摆放，不复制其中人物或个人道具。[使用示例](references/examples.md) 提供最简输入和分享说明。
- 所有相对路径以本 skill 文件夹为基准。先解析为实际绝对路径再传给工具；不依赖原作者电脑。参考图和预览只读。
- 需要一张清楚的人物照片（本人、同事或公众人物均可）。没有照片请用户上传；用户明确要虚构人物时可直接创作。照片不可访问时说明缺少哪张，不编造已看过。
- 照片决定可见发型、发色、肤色、眼镜形状和服饰；定稿参考只决定画风和场景语言。用户明确说明优先于照片。不根据外观推断岗位、姓名或个人背景。
- 办公/居家、服装、1–3 件道具、宠物、透明底、姓名岗位均为可选。不用长问卷阻塞首次出图。

用户只上传照片时，默认居家浅木桌、普通家用椅、银灰笔记本和桌边小型 SlashVibe 产品；服装沿用照片，未显示的下装用简单深色长裤和普通鞋；纯白底。不默认添加宠物、饮料、耳饰或书。名字岗位放在交付文字中，不画在图里。

## SlashVibe 产品硬性规则

- 每张独立人物图的桌面（含矮桌）上必须出现 **恰好一台 SlashVibe**，不能省略、遮住、裁掉或放到地上；不因场景、职业或配件变化取消。
- 外形以 `assets/product-stand.png` 为准，大小以 `assets/product-scale-reference.png` 的最新定稿为准。产品整体外接框宽度约为画面中桌面投影宽度的 **10%**（检查容差 9–11%），约为笔记本外接框宽度的四分之一；不能随画面大小变成大平板。使用相对比例而非固定像素。
- 底座固定朝 **画面左侧**伸出（观众视角，与人物左右无关），与斜板连续相接。禁止镜像、反向、左右双底座、悬空或丢底座。
- 锁定银灰斜板、圆角、单条黑色斜线及原有板/底座比例。只允许整体等比缩放、平移和与桌面一致的自然透视；禁止横纵独立缩放、拉长、压扁、弯曲、重设计或改变底座结构。
- 后续改人脸、衣服、桌搭时锁定产品。图像生成不能保证逐像素不变；如出现变形或方向错误，不能当合格结果交付。需要严格保形时，使用用户已允许的原资产复制/合成流程，不能通过再次生成声称直接复制。

## 生成

1. 使用当前环境的内置图像生成工具（例如 Codex 的 `$imagegen`）。即使辅助 skill 未安装，本包也保留了完整生成要求。默认无需 API key。
2. 逐张查看用户照片、定稿图及请求中的宠物图，明确每图角色。不要把团队里别人的猫、眼镜、服装或酒杯当成新用户默认特征。
3. 生成一个独立方形 PNG，目标约 1024×1024，实际以工具输出为准。完整人物、鞋、家具及物件都在画内，四周留白。不用拉伸来凑尺寸。不画名字、岗位、说明或水印。
4. 默认纯白背景；要求透明底时使用工具的透明背景参数，并保留真实 alpha。
5. 本地照片可选用提示词助手：

   `python3 scripts/build_prompt.py --photo "/absolute/path/me.jpg" --scene home --appearance "保留黑框眼镜和暖小麦肤色" --accessory "一只小咖啡杯" --output "/absolute/path/avatar-request.json"`

   助手仅整理输入，不联网、不上传、不生成。输出 `prompt`、`referenced_image_paths` 和 `transparent_background`，可传给内置图像工具；先进入本 skill 目录或使用脚本绝对路径。用户精确要求仍可补充到 prompt。附件只有对话引用时直接使用工具支持的附件引用，不虚构本地路径。
6. 工具不可用时说明无法完成出图，可以交付 prompt；不能把提示词、示意 SVG 或参考图冒充新生成结果。不要自动转用收费 API 或安装生成服务。

## 检查与修改

交付前必须核对产品存在、桌面位置、9–11% 桌宽比例、左伸底座及无变形；同时检查桌面边线与桌腿透视一致、所有物件完整落在桌面上。书和工作稿默认朝向人物，电脑屏幕与键盘朝向人物，不能把屏幕画到机盖背面。

先按正常展示尺寸检查构图，再放大检查脸、眼镜、手、宠物和产品。依照 [检查标准](references/style-guide.md) 处理确实可见的问题。

- 保持自然均匀肤色和清楚边缘，不默认做全图降噪、磨皮、模糊或描摹。
- 修改已有图时写明“仅改 X，锁定其余外观、姿态、物件和构图”，沿用最新合格版。
- 同一问题最多连续做两次局部生成修正；仍漂移就返回最近合格版并说明问题，不无限叠加修改或承诺逐像素不变。
- 多人需求按人分别生成、检查。纯裁切、改名、排版或复制已有产品时使用确定性的裁切/复制/排版，不重画整张团队图。
- 位图不等于可编辑矢量稿；不承诺 Illustrator 自动描摹能无损复刻。

## 交付

显示实际生成的图，把项目 PNG 保存到当前任务输出目录，默认 `chibi-avatar.png`，避免覆盖已有版本。同时保存最终 prompt，简述使用了内置生成工具及实际检查结果；未检查的部分不能声称通过。只要求个人图时，不自动改共享 Figma、发消息或上传其他服务。

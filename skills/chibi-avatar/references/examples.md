# 使用示例

在新对话上传本人照片，并调用此 skill（Codex 写 `$chibi-avatar`，Claude Code 写 `/chibi-avatar`，下文以 Codex 为例）。需要当前环境能使用内置图像生成工具，无需 Figma、Illustrator 或单独 API key；没有生图工具时只能拿到 prompt。

## 最简单

`用 $chibi-avatar，按我的照片做一个同款团队小人。`

应直接用默认居家场景做一人一图，不生成 14 人团队，也不反复追问姓名岗位。

## 指定特征

`用 $chibi-avatar。保留黑框眼镜和暖小麦肤色，居家办公，浅木桌，桌上放一只小咖啡杯。纯白底。`

## 带宠物

`用 $chibi-avatar，第一张是我，第二张是猫。让我盘腿坐在矮桌前，猫在旁边看产品；猫是暖灰虎斑、绿色虹膜，前爪完整清楚。`

两张照片分别用于人和猫，不互换；不用别人的猫作身份参考。

## 透明底

`用 $chibi-avatar，保留眼镜，做办公桌前的全身角色，透明背景。桌面必须保留一台 SlashVibe，沿用定稿小尺寸、左伸底座和原始形状。`

## 改已有图

`这张已经定稿，只把猫的虹膜改成照片中的黄绿色。人物、肤色、杯子、产品和底座位置保持。`

如果只要求从合图裁切，直接裁切，不能再次生成。

## 分享与安装

完整安装说明见仓库根目录 README。分享时保留整个 `chibi-avatar` 目录，保持 `SKILL.md`、`agents`、`assets`、`references`、`scripts` 的相对位置，不要改成某台电脑的绝对路径。真人原始照片不在包内，由每人自己提供。
